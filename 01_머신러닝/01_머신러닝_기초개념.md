# 머신러닝 기초 개념

## 1. 머신러닝이란?
> "명시적으로 프로그래밍하지 않고, **데이터로부터 패턴을 학습**해 예측·결정을 하는 방법"

- 전통 프로그래밍: `규칙 + 데이터 → 답`
- 머신러닝: `데이터 + 답 → 규칙(모델)`

## 2. 학습 유형

| 유형 | 정답(label) | 목표 | 예시 |
|---|---|---|---|
| 지도학습 (Supervised) | 있음 | 입력 → 출력 매핑 학습 | 집값 예측(회귀), 스팸 분류(분류) |
| 비지도학습 (Unsupervised) | 없음 | 데이터 구조 발견 | 고객 군집화, 차원 축소 |
| 준지도학습 (Semi-supervised) | 일부 | 적은 라벨 + 많은 비라벨 데이터 활용 | 의료 영상 |
| 자기지도학습 (Self-supervised) | 데이터에서 자동 생성 | 표현(representation) 학습 | LLM의 다음 토큰 예측 |
| 강화학습 (Reinforcement) | 보상(reward) | 누적 보상 최대화하는 정책 학습 | 게임 AI, 로봇 제어, RLHF |

## 3. 핵심 용어
- **샘플(sample)**: 데이터 한 건 (행)
- **특성(feature)**: 입력 변수 (열), `X`
- **타깃/레이블(target/label)**: 예측 대상, `y`
- **모델(model)**: 입력 → 출력 함수 `f(X; θ)`
- **파라미터(parameter)**: 학습으로 정해지는 값 (가중치 θ)
- **하이퍼파라미터(hyperparameter)**: 사람이 정하는 설정 (학습률, 트리 깊이 등)
- **손실 함수(loss)**: 예측이 얼마나 틀렸는지 측정
- **학습(training)**: 손실을 최소화하는 파라미터 찾기 = 최적화

## 4. 일반화(Generalization)
목표는 훈련 데이터를 외우는 것이 아니라 **처음 보는 데이터에서 잘 맞추는 것**.

- **과소적합(Underfitting)**: 모델이 너무 단순 → 훈련/테스트 모두 성능 나쁨
- **과적합(Overfitting)**: 모델이 훈련 데이터의 노이즈까지 외움 → 훈련 성능↑, 테스트 성능↓

```
오차
 │ \                          / 테스트 오차
 │  \        최적점          /
 │   \_______ ● ___________/
 │    \_______________
 │                    \______ 훈련 오차
 └──────────────────────────── 모델 복잡도
   과소적합            과적합
```

### 과적합 해결법
1. 데이터 더 모으기 / 데이터 증강
2. 모델 단순화 (특성 수↓, 트리 깊이↓)
3. 규제(Regularization): L1, L2
4. 교차검증으로 하이퍼파라미터 선택
5. 조기 종료(Early stopping), 앙상블

## 5. 편향-분산 트레이드오프 (Bias-Variance Tradeoff)
기대 오차 = **편향² + 분산 + 줄일 수 없는 노이즈**

- **편향(Bias)**: 모델 가정이 너무 단순해서 생기는 체계적 오차 → 과소적합
- **분산(Variance)**: 훈련 데이터가 조금만 바뀌어도 모델이 크게 바뀜 → 과적합
- 복잡도를 올리면 편향↓ 분산↑ → 균형점을 찾는 것이 핵심

## 6. 데이터 분할
| 세트 | 용도 |
|---|---|
| Train | 파라미터 학습 |
| Validation | 하이퍼파라미터/모델 선택 |
| Test | **최종 1회** 성능 측정 (절대 튜닝에 사용 X) |

일반적 비율: 60/20/20 또는 80/20 + 교차검증

## 7. "공짜 점심은 없다" (No Free Lunch)
모든 문제에 최고인 알고리즘은 없다 → 문제·데이터에 맞게 여러 모델을 비교해야 함.

## ✅ 체크리스트
- [ ] 지도/비지도/강화학습의 차이를 예시와 함께 설명할 수 있다
- [ ] 파라미터와 하이퍼파라미터를 구분할 수 있다
- [ ] 과적합의 증상과 해결법 3가지 이상을 말할 수 있다
- [ ] 편향-분산 트레이드오프를 그림으로 설명할 수 있다
- [ ] 테스트 세트를 튜닝에 쓰면 안 되는 이유를 안다
