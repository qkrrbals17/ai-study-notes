# 데이터 전처리 & 특성 공학 (Feature Engineering)

> "Garbage in, garbage out" — 실무 ML 시간의 대부분은 데이터 준비에 쓰인다.

## 1. 탐색적 데이터 분석 (EDA)
```python
import pandas as pd
df = pd.read_csv("data.csv")
df.info()            # 타입, 결측치
df.describe()        # 통계 요약
df.isna().sum()      # 열별 결측치 수
df["target"].value_counts(normalize=True)  # 클래스 불균형 확인
df.corr(numeric_only=True)                 # 상관관계
```
확인할 것: 분포(왜도), 이상치, 결측 패턴, 클래스 불균형, 변수 간 상관

## 2. 결측치 처리
| 방법 | 언제 |
|---|---|
| 행 삭제 | 결측이 매우 적고 무작위일 때 |
| 열 삭제 | 결측 비율이 매우 높을 때 |
| 평균/중앙값/최빈값 대체 | 간단한 기본값 (`SimpleImputer`) |
| 모델 기반 대체 | KNN, 반복 대체(`IterativeImputer`) |
| 결측 여부 플래그 추가 | 결측 자체가 정보일 때 |

## 3. 이상치(Outlier)
- 탐지: IQR 규칙 (Q1−1.5·IQR, Q3+1.5·IQR), Z-score, Isolation Forest
- 처리: 제거, 클리핑(winsorizing), 로그 변환, 강건한 모델 사용(트리 계열)

## 4. 스케일링
거리·경사하강 기반 모델(KNN, SVM, 선형모델, 신경망)에 중요. 트리 모델은 거의 영향 없음.

| 방법 | 수식 | 특징 |
|---|---|---|
| StandardScaler | (x−μ)/σ | 평균 0, 표준편차 1 |
| MinMaxScaler | (x−min)/(max−min) | [0,1] 범위, 이상치에 민감 |
| RobustScaler | (x−median)/IQR | 이상치에 강건 |
| 로그/Box-Cox/Yeo-Johnson | — | 치우친 분포를 정규에 가깝게 |

## 5. 범주형 변수 인코딩
| 방법 | 설명 | 주의 |
|---|---|---|
| One-Hot | 범주마다 0/1 열 | 범주 많으면 차원 폭발 |
| Ordinal/Label | 정수 매핑 | 순서 없는 범주에 선형모델 쓰면 왜곡 |
| Target Encoding | 범주별 타깃 평균 | **누수 위험** → 교차검증 방식으로 |
| Frequency Encoding | 등장 빈도 | 간단하고 트리에 유용 |

## 6. 특성 생성 아이디어
- 날짜: 연/월/요일/주말 여부/공휴일/경과일
- 수치 조합: 비율(가격/면적), 차이, 곱(상호작용)
- 그룹 집계: 고객별 평균 구매액, 최근 N일 횟수
- 텍스트: 길이, TF-IDF, 임베딩
- 도메인 지식이 가장 강력한 특성을 만든다

## 7. 특성 선택
- 필터: 상관계수, 카이제곱, 상호정보량
- 래퍼: RFE(재귀적 특성 제거)
- 임베디드: Lasso(L1), 트리 feature importance, Permutation importance, SHAP

## 8. 클래스 불균형
- 지표를 Accuracy 대신 F1, PR-AUC로
- `class_weight="balanced"`
- 오버샘플링(SMOTE), 언더샘플링
- 결정 임계값(threshold) 조정

## 9. ⚠️ 데이터 누수 (Data Leakage)
훈련 시점에 알 수 없는 정보가 모델에 들어가는 것 → 검증 점수는 높지만 실전에서 망함.
- 전체 데이터로 스케일러를 fit 한 뒤 분할 ❌ → **분할 후 train에만 fit**
- 미래 정보를 포함한 특성 (예: 시계열에서 무작위 분할)
- 타깃에서 파생된 특성
- 해결: `Pipeline`으로 전처리와 모델을 묶어 교차검증

```python
from sklearn.pipeline import Pipeline
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.impute import SimpleImputer
from sklearn.linear_model import LogisticRegression

num = Pipeline([("imp", SimpleImputer(strategy="median")), ("sc", StandardScaler())])
cat = Pipeline([("imp", SimpleImputer(strategy="most_frequent")),
                ("oh", OneHotEncoder(handle_unknown="ignore"))])
pre = ColumnTransformer([("num", num, num_cols), ("cat", cat, cat_cols)])
model = Pipeline([("pre", pre), ("clf", LogisticRegression(max_iter=1000))])
```

## ✅ 체크리스트

- [ ] 데이터 누수 사례 3가지를 들 수 있다
