# 비지도 학습 (Unsupervised Learning)

정답 없이 데이터의 **구조**를 찾는다: 군집화, 차원 축소, 이상 탐지

## 1. 군집화 (Clustering)

### K-Means
1. K개 중심 무작위 초기화 (보통 **k-means++**)
2. 각 점을 가장 가까운 중심에 할당
3. 중심을 할당된 점들의 평균으로 이동
4. 수렴할 때까지 반복
- 목표: 군집 내 제곱거리합(Inertia) 최소화
- K 정하기: **엘보우 방법**, **실루엣 점수**
- 한계: 구형·비슷한 크기 군집 가정, 이상치 민감, 스케일링 필요

### 계층적 군집 (Hierarchical)
- 병합형: 각 점을 하나의 군집으로 시작해 가까운 것끼리 합침
- 연결 방식: single, complete, average, **ward**
- **덴드로그램**으로 시각화 → 원하는 높이에서 잘라 군집 수 결정

### DBSCAN
- 밀도 기반: 반경 `eps` 내 이웃이 `min_samples` 이상이면 핵심점
- **임의 모양 군집** 가능, **K 지정 불필요**, 노이즈(이상치) 자동 분리
- 밀도가 다양한 데이터엔 약함 → HDBSCAN

### 가우시안 혼합 모델 (GMM)
- 데이터가 여러 정규분포의 혼합이라 가정, **EM 알고리즘**으로 학습
- 소프트 클러스터링(확률적 소속), 타원형 군집

| 알고리즘 | K 필요 | 모양 | 이상치 |
|---|---|---|---|
| K-Means | ✓ | 구형 | 민감 |
| 계층적 | 사후 결정 | 다양 | 민감 |
| DBSCAN | ✗ | 임의 | 강건(노이즈 분리) |
| GMM | ✓ | 타원 | 중간 |

## 2. 차원 축소 (Dimensionality Reduction)
목적: 시각화, 노이즈 제거, 연산량 감소, 차원의 저주 완화

### PCA (주성분 분석)
- 분산이 최대인 방향(주성분)으로 데이터를 투영하는 **선형** 변환
- 공분산 행렬의 고유벡터 = 주성분, 고유값 = 설명 분산
- `explained_variance_ratio_`로 누적 95% 등 기준 선택
- 스케일링 필수

### t-SNE / UMAP
- **비선형**, 주로 2D/3D **시각화** 용
- t-SNE: 지역 구조 보존 우수, 느림, 축/거리 해석 불가
- UMAP: 더 빠르고 전역 구조도 비교적 보존
- ⚠️ 시각화 결과의 군집 크기·거리를 과하게 해석하지 말 것

### 기타
- LDA(선형판별분석, 지도형), Autoencoder(딥러닝), Truncated SVD(희소 행렬/텍스트)

## 3. 이상 탐지 (Anomaly Detection)
- Isolation Forest: 이상치는 적은 분할로 고립된다
- One-Class SVM, LOF(Local Outlier Factor)
- Autoencoder 재구성 오차

## 4. 평가 (정답이 없을 때)
- 실루엣 점수 (−1~1, 높을수록 좋음)
- Davies-Bouldin (낮을수록 좋음), Calinski-Harabasz (높을수록 좋음)
- 결국 **도메인 관점에서 해석 가능한지**가 중요

## 5. 코드
```python
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.decomposition import PCA
from sklearn.metrics import silhouette_score

Xs = StandardScaler().fit_transform(X)
for k in range(2, 9):
    km = KMeans(n_clusters=k, n_init="auto", random_state=0).fit(Xs)
    print(k, km.inertia_, silhouette_score(Xs, km.labels_))

X2 = PCA(n_components=2).fit_transform(Xs)   # 시각화용
```
