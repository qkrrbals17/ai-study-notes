===== 조립된 프롬프트 =====
<role>
당신은 쇼핑몰 고객센터의 문의 분류 담당자입니다.
</role>

<rules>
- 카드 이중결제, 계정 도용은 긴급도 5
- 개인정보는 summary에 넣지 않는다
- 확신이 없으면 needs_human=true
</rules>

<example id="1">
<input>배송이 일주일째 안 와요</input>
<output>{"category":"배송","urgency":3,"summary":"배송 지연 1주","needs_human":false}</output>
</example>

<format>
JSON 한 개만 출력. 스키마: {"category": {"enum": ["결제", "배송", "계정", "기타"], "title": "Category", "type": "string"}, "urgency": {"description": "1(낮음)~5(긴급)", "maximum": 5, "minimum": 1, "title": "Urgency", "type": "integer"}, "summary": {"maxLength": 60, "title": "Summary", "type": "string"}, "needs_human": {"title": "Needs Human", "type": "boolean"}}
</format>

<task>
고객 문의: '어제 결제했는데 카드에서 두 번 빠져나갔어요. 빨리 확인 부탁드립니다.'
</task>
...

❌ 시도 1: 검증 실패 → category: Input should be '결제', '배송', '계정' or '기타'; urgency: Input should be less than or equal to 5
✅ 시도 2: 검증 통과 → category='결제' urgency=5 summary='카드 이중 결제 확인 요청' needs_human=True

후속 처리 예: 상담원 연결
