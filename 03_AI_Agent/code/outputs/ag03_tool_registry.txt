   → 4.5

   → 인자 오류: 'scale'는 ['letter', 'gpa'] 중 하나여야 합니다 (받은 값: percent)

   → 오류: 'search_students' 도구는 없습니다. 사용 가능: ['search_student', 'convert_grade', 'slow_api', 'send_email']
